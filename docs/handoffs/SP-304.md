## 1. Scope completed
- **Route Guard Domain Logic (`backend/app/soulmate/domain/guard.py`):**
  - Pure function `evaluate_route_guard` implementing the exact route prerequisite and redirection table from DEV-SPEC §3:
    1. `/soulmate/quiz`: requires active session; if missing, redirects to `/soulmate` to create a new session.
    2. `/soulmate/email`: requires Quiz completed; if not met, redirects back to current quiz step (`/soulmate/quiz?step={current_step}`).
    3. `/soulmate/subscribe`: requires Email captured; if not met, redirects to `/soulmate/email`.
    4. `/soulmate/result`: requires first payment confirmed per `PAY-AUTH-01`; if not met, redirects to `/soulmate/subscribe`.
    5. `/soulmate/sketch`: requires first payment confirmed AND 12h unlock cooldown reached per `TIME-01`; if not met, redirects to `/soulmate/result`.
    6. `/soulmate/report`: requires first payment confirmed AND 24h unlock cooldown reached per `TIME-01`; if not met, redirects to `/soulmate/result`.
  - Pure function `calculate_unlock_times`: authoritative calculation of sketch (+12h) and report (+24h) unlock timestamps from confirmed payment time (`TIME-01`).
- **Pydantic Schema Contract (`backend/app/soulmate/schema.py`):**
  - Added `RouteGuardResponse` schema containing `allowed`, `target_route`, `redirect_to`, `reason`, `server_time`, `session_id`, `quiz_completed`, `email_captured`, `is_paid`, `sketch_unlocked`, `report_unlocked`, `sketch_unlock_at`, and `report_unlock_at`.
- **Backend Service Layer (`backend/app/soulmate/services/guard_service.py`):**
  - Implemented async `GuardService.evaluate_guard` reading server-persisted database truth (session status, quiz completion, email normalization, subscription payment state, and UTC server time).
  - Enforces `PAY-AUTH-01`: server/provider confirmation of first payment is the exclusive authority for result access.
  - Enforces `TIME-01`: server UTC timestamp determines sketch (12h) and report (24h) unlock states; browser local clock is strictly non-authoritative.
- **HTTP API Endpoint (`backend/app/api/soulmate/guard.py`, `router.py`):**
  - Mounted `GET /api/soulmate/guard/check?target_route=...` endpoint with optional session support and `verify_session_ownership` IDOR protection (DEV-SPEC §20).
- **Frontend Client & Hook (`frontend/src/soulmate/api/guard.ts`, `frontend/src/soulmate/hooks/useRouteGuard.ts`):**
  - Added typed `checkRouteGuard` client function.
  - Implemented React hook `useRouteGuard({ targetRoute, sessionId, enabled })`:
    - Queries server on mount for authoritative verdict.
    - If `!allowed && redirect_to`, automatically triggers client navigation to `redirect_to`.
    - Resilient against offline/dev environments and server-side rendering.
  - Wired `useRouteGuard` into `/soulmate/email`, `/soulmate/subscribe`, `/soulmate/result`, `/soulmate/sketch`, and `/soulmate/report` pages while preserving test fixture isolation.
- **Automated Verification:**
  - 12 backend unit, service, and API tests in `backend/tests/test_route_guards.py`.
  - 4 frontend unit tests in `frontend/tests/route-guard.test.ts`.

## 7. High-risk checks when applicable
- Authorization / ownership: `verify_session_ownership` prevents IDOR inspection of foreign sessions' route guards (returns 403).
- PAY-AUTH-01 compliance: Client payment tokens/callbacks cannot bypass result access; requires server-recorded first payment on `Subscription`.
- TIME-01 compliance: Browser time manipulation cannot unlock Sketch or Report prematurely; `server_time` in UTC is authoritative.

## 8. Deviations / implementation decisions
- **C-1 Audit Remediation (Fail-Closed Policy):** Remediated initial fail-open error handling in `useRouteGuard.ts`. Implemented `resolveGuardFailurePolicy` enforcing strict fail-closed (`allowed: false`) on API failure or network loss for all high-value paid routes (`/soulmate/result`, `/soulmate/sketch`, `/soulmate/report`). - Kept fallback behavior in client components for test fixture / offline preview modes (`searchParams.get("fixture") === "true"`), allowing fixture development and tests to function while enforcing strict production guards.
