## 8. Deviations / implementation decisions
- **Figma `102:14` does not contain the `Soulmate Sketch` link** (it shows Privacy Policy / Terms of use / Subscribe policy / Setting / Log out). Placement as the FIRST item with identical link styling was chosen because it is the primary product entry; flagged for owner confirmation. Changing position/order later is a one-line change in `nav.ts`.
- **No drawer trigger exists anywhere in the Figma source.** A hamburger trigger was added to the landing TopAppBar (right cluster: Login + menu icon) because Figma `102:14` depicts the drawer over landing content and the entry must be reachable. This is a minor visual addition to Figma `102:44`; flagged for owner confirmation.
- `DrawerMenuButton` gracefully falls back to a locally-controlled `AccountDrawer` when no provider is mounted (standalone/test rendering only; production always mounts the provider, so exactly one instance exists at runtime).
- Log out / policy links are inert placeholders pending auth and legal pages (existing convention: landing footer already uses dead `#privacy` / `#terms` anchors).
