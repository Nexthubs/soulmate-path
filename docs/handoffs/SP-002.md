## 7. High-risk checks when applicable
- **Authorization / ownership:** Foreign keys enforce cascading delete on answers/profiles to session; `subscriptions` and `artifacts` require valid session references.
- **Idempotency / concurrency:** Webhooks enforced unique by `paypal_event_id`; AI generation jobs enforced unique by `idempotency_key`.
- **Payment / entitlement authority:** `subscriptions` requires valid provider IDs; timestamps strictly UTC.
- **Asset durability (ASSET-01):** Partial unique index `uq_soulmate_one_sketch_per_email` prevents multiple sketches for same normalized email at the DB engine level.

## 8. Deviations / implementation decisions
- Implemented both synchronous engine (`psycopg3`) for Alembic and tests, and asynchronous engine (`asyncpg`) for FastAPI async endpoints in `backend/app/db/session.py`.
- Timestamps explicitly specify `DateTime(timezone=True)` to ensure PostgreSQL creates `timestamptz` columns.

## 9. New risks / TBDs / known limitations

- Production migration runner strategy will need to be configured in CI/CD before deployment.
