## 8. Deviations / implementation decisions
- **Production config gate workaround:** a production-mode browser render with localhost env throws in `ConfigValidator` (error boundary), so the recording build baked production-shaped values (`https://soulmate.giaogiao.work` form + PayPal client + PAY-01 prices) via process env; the recording proxy rewrites the baked API fetches to the same-origin local proxy at document start. No app file modified; the only bundle delta is inlined env constants. Recorded in the baseline doc §2.
- **React render-count instrumentation:** the standard DevTools hook + `PerformedWork` approach does not work on React 19 production builds; implemented the alternate-reference discrimination described above (validated: hook.inject fired, per-tap attribution matches labeled components).
- **Recording tooling:** IAB background recordings produce empty/stub WebM artifacts; all valid recordings use the recorder's scripted-action mode with explicit selectors and delays.
- **Task registration:** the execution plan's batches were not registered tasks; per the plan's own instruction, batch 0 was registered as SP-1101 in `TASK-BREAKDOWN.md` before handoff. Batch numbering for later batches (1/2/3/3B/4) still requires registration when authorized.
