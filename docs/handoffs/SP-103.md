## 1. Scope completed
- Implemented `OptionCard` (`frontend/src/soulmate/components/quiz/OptionCard.tsx`) as the shared visual primitive for both single-choice and multi-choice questions matching Figma nodes `102:130` and `102:137`:
  - Selected state: `bg-white/80 border-2 border-[#5c3c4f] shadow-xs text-[#111827]` with filled `#5c3c4f` circular indicator and white checkmark icon.
  - Unselected state: `bg-white/60 hover:bg-white/90 border-2 border-transparent text-[#1f2937]` with gray stroke indicator.
  - Disabled state: `opacity-50 cursor-not-allowed pointer-events-none` for submission locks (DEV-SPEC §4.2).
  - Error state: `border-2 border-red-400 bg-red-50/70` for validation highlighting.
  - Focus state: `focus-visible:ring-2 focus-visible:ring-purple-600 focus-visible:ring-offset-2`.
- Unified single and multi semantics via `selectionType: "single" | "multi"`:
  - Maps to `role="radio"` for single-choice and `role="checkbox"` for multi-choice.
  - Manages `aria-checked` and keyboard triggering (`Space` / `Enter`).
  - Mobile touch target exceeds 48px standard (`min-h-[68px]` with `p-5` padding).
- Integrated `OptionCard` into `/soulmate/quiz` route (`frontend/src/app/soulmate/quiz/page.tsx`), powering both Q02 (single) and Q18 (multi) options.
- Implemented automated test suite (`frontend/tests/option-card.test.tsx`) covering visual states, ARIA roles, disabled lock, error state, and touch target sizing.
